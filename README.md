# Git Lab Project

## Project Title
Basic C Programming Practice

## Objective
The objective of this project is to practice basic C programming concepts while using Git and GitHub for version control.

## Programs Included

### calculator.c
A simple calculator program that performs basic arithmetic operations on two numbers.

### student_record.c
A simple program that accepts basic student information and displays the student record.

## How to Run

Compile a program using a C compiler:

    gcc calculator.c -o calculator

Then run:

    .\calculator.exe

Similarly, for the student record program:

    gcc student_record.c -o student_record

    .\student_record.exe

## Git Concepts Practiced

- Git repository initialization
- Tracking files
- Staging and committing
- Branching
- Merging
- Merge conflict resolution
- GitHub remote repository
- .gitignore
